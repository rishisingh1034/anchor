# Anchor — AWS Services & Teardown Guide

This document lists all AWS services and resources provisioned for the **Anchor** project, along with step-by-step instructions and automated CLI commands to tear them down when no longer needed.

---

## 1. Summary of AWS Services Used

| Service                 | Purpose                                                                          | Pricing / Provisioning Model                                         |
| ----------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **AWS Amplify Hosting** | Hosts the Anchor Next.js 15 SSR dashboard and API backend                        | Pay-as-you-go (build minutes + SSR compute requests + data transfer) |
| **Amazon S3**           | Stores the static build output files (HTML/CSS/JS/images) for each deployed site | Standard S3 storage per bucket                                       |
| **Amazon CloudFront**   | Global CDN distribution serving HTTPS traffic for each deployed static site      | Pay-per-request / data transfer out (Free tier includes 1 TB/mo)     |
| **Amazon DynamoDB**     | Stores deployment history records (owner, repo, status, liveUrl, timestamp)      | On-Demand (Pay-per-request)                                          |
| **AWS IAM**             | Service and Compute execution role with least-privilege permissions              | Free                                                                 |
| **Amazon Bedrock**      | AI foundation model (`amazon.nova-lite-v1:0`) for analyzing repo manifests       | Serverless pay-per-token (no standing infrastructure to delete)      |
| **Amazon CloudWatch**   | Execution logs generated by Amplify builds and SSR compute                       | Standard log storage                                                 |

## 3. Teardown Instructions

When you are ready to remove all resources, run the commands below in your terminal.

### Step 1: Delete the AWS Amplify App

Deleting the Amplify app tears down the SSR compute Lambda, build jobs, and domain mappings:

```bash
aws amplify delete-app --app-id dnnu4lkh82cpn --region us-east-1
```

### Step 2: Delete S3 Deployment Buckets

Delete all objects and remove the site buckets:

```bash
for bucket in $(aws s3api list-buckets --query "Buckets[?starts_with(Name, 'anchor-site')].Name" --output text); do
  echo "Deleting S3 bucket: $bucket"
  aws s3 rm "s3://$bucket" --recursive
  aws s3api delete-bucket --bucket "$bucket" --region us-east-1
done
```

### Step 3: Disable and Delete CloudFront Distributions

> [!NOTE]
> CloudFront requires distributions to be **Disabled** before deletion. Disabling takes ~1–2 minutes to propagate.

```bash
# 1. Disable all Anchor distributions
for dist_id in ET5B69YMX3I3K E31I6DMNGH3XXW EOFWAG4RAK1A0 E2B5HHTVGQ147L E1Y1OQKQLKNW39; do
  echo "Disabling distribution $dist_id..."
  ETAG=$(aws cloudfront get-distribution-config --id "$dist_id" --query "ETag" --output text)
  aws cloudfront get-distribution-config --id "$dist_id" --query "DistributionConfig" > /tmp/dist-config.json
  # Update Enabled to false
  sed -i 's/"Enabled": true/"Enabled": false/' /tmp/dist-config.json
  aws cloudfront update-distribution --id "$dist_id" --if-match "$ETAG" --distribution-config file:///tmp/dist-config.json > /dev/null
done

# 2. Once Status is "Deployed" (after ~2 minutes), delete them:
for dist_id in ET5B69YMX3I3K E31I6DMNGH3XXW EOFWAG4RAK1A0 E2B5HHTVGQ147L E1Y1OQKQLKNW39; do
  echo "Deleting distribution $dist_id..."
  ETAG=$(aws cloudfront get-distribution-config --id "$dist_id" --query "ETag" --output text)
  aws cloudfront delete-distribution --id "$dist_id" --if-match "$ETAG"
done

# 3. Delete Origin Access Controls (OAC)
for oac_id in E23K1JR9AROY6G E2ZG8ILDIAR2F7 EFVMJ8JN7VDIR E1CPOJDZML30W2 E2NE690UG8MN97; do
  ETAG=$(aws cloudfront get-origin-access-control --id "$oac_id" --query "ETag" --output text)
  aws cloudfront delete-origin-access-control --id "$oac_id" --if-match "$ETAG"
done
```

### Step 4: Delete DynamoDB Tables

```bash
aws dynamodb delete-table --table-name deployments --region us-east-1
# If ap-south-1 table exists:
aws dynamodb delete-table --table-name deployments --region ap-south-1 2>/dev/null || true
```

### Step 5: Delete IAM Role & Policies

```bash
# 1. Delete build service role
aws iam detach-role-policy --role-name anchor-amplify-service-role --policy-arn arn:aws:iam::aws:policy/AdministratorAccess-Amplify
aws iam delete-role-policy --role-name anchor-amplify-service-role --policy-name anchor-runtime-policy
aws iam delete-role --role-name anchor-amplify-service-role

# 2. Delete compute role
aws iam delete-role-policy --role-name anchor-amplify-compute-role --policy-name anchor-runtime-policy
aws iam delete-role --role-name anchor-amplify-compute-role
```

### Step 6: Delete CloudWatch Log Group

```bash
aws logs delete-log-group --log-group-name "/aws/amplify/dnnu4lkh82cpn" --region us-east-1
```

## 4. One-Shot Automated Cleanup Script

You can save and run this single script (`scripts/teardown.sh`) when you want to clean up everything at once:

```bash
#!/usr/bin/env bash
set -e

echo "=== Starting Anchor AWS Teardown ==="

echo "1. Deleting Amplify App..."
aws amplify delete-app --app-id dnnu4lkh82cpn --region us-east-1 || true

echo "2. Deleting S3 Buckets..."
for bucket in $(aws s3api list-buckets --query "Buckets[?starts_with(Name, 'anchor-site')].Name" --output text); do
  echo "  Deleting S3 bucket: $bucket"
  aws s3 rm "s3://$bucket" --recursive || true
  aws s3api delete-bucket --bucket "$bucket" --region us-east-1 || true
done

echo "3. Deleting DynamoDB Table..."
aws dynamodb delete-table --table-name deployments --region us-east-1 || true

echo "4. Deleting IAM Role..."
aws iam detach-role-policy --role-name anchor-amplify-service-role --policy-arn arn:aws:iam::aws:policy/AdministratorAccess-Amplify || true
aws iam delete-role-policy --role-name anchor-amplify-service-role --policy-name anchor-runtime-policy || true
aws iam delete-role --role-name anchor-amplify-service-role || true

echo "5. Deleting CloudWatch Logs..."
aws logs delete-log-group --log-group-name "/aws/amplify/dnnu4lkh82cpn" --region us-east-1 || true

echo "=== Teardown Complete (Remember to delete CloudFront distributions after they finish disabling) ==="
```
